What this gives a youth ministry

The value is not just “a Christian game.” The value is a repeatable discipleship touchpoint that connects memory, teaching, discussion, and shared play.

Reinforce the week’s message

Create custom worlds that emphasize categories like faith, courage, wisdom, or identity, then point your students to play between gatherings.

Go beyond memory only

Use the new discipleship path to walk students through the commandments and promises of Jesus with built-in review and reflection instead of stopping at recall alone.

Use it live in a room

Start students in solo or multiplayer, then use the help/tutorial tools and review flow to anchor conversation afterward.

Keep Scripture tied to action

The game loop itself rewards correct answers. Learning is not bolted on after the fun; it drives the fun.
