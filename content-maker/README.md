# Content Maker Strategy

## Purpose

`content-maker/` is for the internal content production system only.

It is not the place where public SEO pages should be published.

Public long-form SEO content should be published under:

- `resources/`

This keeps the content tool separate from the published site structure and avoids accidental coupling between the app, the editor workflow, and indexed content.

## Publishing Structure

Recommended public content structure:

- `resources/youth-pastors/`
- `resources/missions/`
- `resources/parents/`
- `resources/blog/`

Existing audience landing pages can continue to live at the root:

- `/youth-pastors`
- `/parents`
- `/players`

Long-form content should sit under `resources/` and link into those higher-conversion landing pages or directly into the game where appropriate.

## Where Content Should Live

Primary recommendation:

- Publish product-relevant SEO content on the VerseBattles site itself.

Use the established Christian website only for:

- broader thought leadership
- general ministry essays
- selective supporting backlinks into VerseBattles resources

Do not split the main content program across both domains unless there is a very clear editorial reason.

## Content Clusters

### Youth Pastors

Intent:

- help youth leaders make Scripture memory more engaging
- show practical ministry use, not just game novelty

Example topics:

- Bible memory games for youth groups
- low-prep youth group Scripture activities
- browser-based discipleship tools for youth ministry

### Missions

Intent:

- position VerseBattles as a useful discipleship and outreach tool in lower-income and lower-bandwidth contexts

Important framing:

- low bandwidth
- low cost
- shared devices
- browser access
- school, church, and outreach use cases

Example topics:

- Scripture memory tools for mission schools
- digital discipleship tools for low-resource churches
- browser-based Bible learning tools for ministry teams

### Parents

Intent:

- show spiritually meaningful screen time and practical family use

Example topics:

- Bible games for families
- Christian alternatives to low-value screen time
- Scripture memory activities for children

### Blog

Intent:

- support the main clusters with broader educational content
- publish synthesis pieces that compare methods, frameworks, and ministry use cases

## What The Content Program Must Optimize For

- high-value pages rather than high-volume pages
- one audience and one search intent per page
- real utility even if search engines did not exist
- product honesty
- sourced insight
- original synthesis
- clear next steps

## What To Avoid

- thin AI pages
- generic Christian filler
- mass-produced near-duplicate keyword pages
- unsupported claims
- pages that could be about any product with minor edits

## Production Model

The AI should be treated as an editorial drafting and synthesis system, not an autonomous content mill.

Recommended flow:

1. Choose one audience, one keyword, and one page goal.
2. Gather a small set of credible sources.
3. Draft a detailed outline.
4. Draft the full page with explicit product relevance.
5. Add images or screenshots that materially support the page.
6. Run a quality gate before publishing.
7. Publish only if the page is genuinely useful and distinct.

## Editorial Standard

Every page should answer yes to these questions:

- Is this useful without SEO intent?
- Is it specific to one audience?
- Does it contain real synthesis?
- Does it cite real sources responsibly?
- Does it connect naturally to VerseBattles?
- Is it clearly different from existing pages?
- Would a missions leader, parent, or youth pastor actually save or share it?
