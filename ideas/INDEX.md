## 5️⃣ Spaced Repetition & Adaptive Difficulty

**File**: `05-SPACED_REPETITION_ADAPTIVE.md`

**What It Does**:
Implement scientifically-proven spaced repetition (Leitner box system + SM-2 algorithm) with real-time adaptive difficulty based on player performance.

**Key Features**:
- 📦 Leitner boxes (4 stages: Learning → Familiar → Mastered → Expert)
- 📅 Spaced reviews (1 day → 3 days → 7 days → 30 days)
- 🎯 Adaptive difficulty (auto-adjust based on accuracy)
- 📊 Smart verse selection (optimal challenge zone)

**Mechanics**:
```
Correct answer → Move up box (longer intervals)
Wrong answer → Move back to Box 1 (review sooner)
Optimal accuracy 70-80% → Flow state maintained
```

**Learning Science**:
- **Ebbinghaus curve**: Reviews prevent memory decay
- **Spacing effect**: Spaced practice > massed practice
- **Interleaving**: Mix difficulties for better learning
- **Optimal challenge**: 70-80% success rate = flow state

**Expected Impact**:
- ✅ 10x ↑ retention (80%+ vs 15% baseline)
- ✅ 50% reduction in study time needed
- ✅ 90%+ mastery rate vs 30% baseline
- ✅ Verses retained 1+ year

**Implementation Time**: 2-3 weeks

**Priority**: 🔴 CRITICAL (Most effective learning)
