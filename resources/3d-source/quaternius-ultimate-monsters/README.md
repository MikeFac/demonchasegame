# Quaternius Ultimate Monsters source

This directory contains the original `Ghost_Skull.gltf` selected for the first
authored Fear monster prototype.

- Creator: Quaternius
- Pack: [Ultimate Monsters](https://quaternius.com/packs/ultimatemonsters.html)
- Original pack folder: [Google Drive](https://drive.google.com/drive/folders/18m4KpzpEzhC9wl7jzr6dUc0N8Jozr79C)
- Selected source file: `Flying/glTF/Ghost_Skull.gltf`
- License: CC0 1.0 Universal; see `License.txt`

The source is retained here for reproducible conversion. The browser loads the
derived GLB from `public/assets/3d/models`, not this working file.
