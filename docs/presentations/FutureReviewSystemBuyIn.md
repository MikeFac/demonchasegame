## Intended Audience

- ministry partners
- church leaders
- Christian school stakeholders
- donors or sponsors
- pilot testers

## Framing

This deck is intentionally not a promise that the feature will be built next.

It positions the review system as:
- a meaningful future capability
- strategically valuable if real people want it
- expensive enough that it should earn buy-in before serious implementation

## Core Message

The presentation should communicate:
- the problem is scripture retention, not only session engagement
- a per-user review system could meaningfully improve long-term verse recall
- this could create stronger ministry value than a pure gameplay feature
- this is a significant capability, not a minor add-on
- therefore it needs partner interest, testing commitment, and possibly sponsorship

## Suggested Use

- use it in partner calls
- use it in fundraising or sponsorship conversations
- use it to test whether ministries actually care about scheduled verse review

## Suggested Presenter Notes

1. Lead with the problem, not the technology.
2. Emphasize that this is about helping people return to Scripture.
3. State clearly that the team is being disciplined about not overbuilding prematurely.
4. Ask for specific forms of buy-in:
   - pilot access
   - testing commitment
   - sponsorship
   - strategic feedback
5. End by asking whether this would solve a real ministry problem for them.
