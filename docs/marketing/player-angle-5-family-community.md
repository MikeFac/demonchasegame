# How to Play Multiplayer

### Step by Step

1. **Create Room**
   - Pick mission/difficulty
   - Set quiz balance
   - Choose map style

2. **Invite Players**
   - Share room code
   - Or join existing room

3. **Start Game**
   - Everyone plays together
   - Answer questions
   - Defeat demons

4. **See Results**
   - Compare scores
   - Learn together
   - Play again!
