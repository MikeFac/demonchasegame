# How to Fight

### Step 1: Answer Quiz Questions
When a demon approaches, answer Bible verse questions to earn **ammo**.

### Step 2: Shoot the Demons
Each correct answer = 1 bullet. Miss, and you leave yourself vulnerable!

### Step 3: Level Up
Earn XP from correct answers. Level up to:
- More health
- Stronger attacks
- Unlock new abilities
