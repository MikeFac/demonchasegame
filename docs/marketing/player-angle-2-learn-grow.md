# How VerseBattles Works

### Active Recall = Better Memory

Each time you play, you actively recall verse content:

**🎯 First Letter Mode**
"The Lord is my ___; I shall not be in want."
→ Answer: "shepherd"

**✍️ Missing Word Mode**
"God so loved the world that He gave His ___ Son..."
→ Answer: "only-begotten"

**✅ True/False Mode**
"John 3:16 says 'For God so loved the world...'"
→ Answer: True or False

**The more you play, the more you remember!**
